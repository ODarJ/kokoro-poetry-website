1. Nature of the project

Kokoro Poetry Video is an open-source automation pipeline that generates English poetry videos using AI-assisted planning, Kokoro text-to-speech, synchronized subtitles, visual backgrounds, and background music. When enabled by the operator, it may publish the resulting videos to accounts that the operator owns and controls, using each platform’s official API.

This website provides information about the project. The pipeline itself is not a hosted service offered to the public. There are no public user accounts and no interactive features that accept content or personal data from third parties.
