Kokoro Poetry Video

An open-source pipeline that turns one English poem a day into a narrated, subtitled poetry video — planned with AI assistance and published through the official platform APIs.

View on GitHub Privacy Policy

What it does

Each day the project picks the next poem from a simple list, asks an AI model once to prepare everything the video needs, and then builds two versions of the video: a 16:9 video for YouTube and a 9:16 vertical video for short-form platforms.

Poems are read aloud with an AI voice. Because the narration is synthetic, the videos say so in their descriptions.

How it works

  1. Select — exactly one pending poem is chosen per calendar day, and the state is remembered so nothing is processed twice.
  2. Plan — one AI request returns the poem details, narration text, mood, voice choice, a background scene plan, music search keywords and platform-specific titles and descriptions.
  3. Gather — footage is downloaded from Pexels and a background track is found on Freesound.
  4. Narrate — Kokoro text-to-speech reads the poem line by line.
  5. Render — FFmpeg combines narration, synchronized subtitles, footage and music (quieter while the voice speaks).
  6. Publish — the videos are uploaded to the platforms that are switched on, and the result of each upload is recorded.

Building blocks

Kokoro TTS

Open-weight text-to-speech model used to narrate each poem with a voice that suits its mood.

Pexels

Free stock photos and videos used as cinematic backgrounds. Only the files needed for the current poem are downloaded.

Freesound

Background music is searched on Freesound and limited to tracks released under Creative Commons 0.

Subtitles & FFmpeg

One subtitle line appears at a time, timed to the narration, with a larger, mobile-safe layout for the vertical video.

Publishing

Publishing uses each platform's official API with OAuth. Credentials are stored as GitHub Actions Secrets and are never written into the code, the logs or the generated files.

YouTube

Uses the YouTube Data API v3 with the upload permission only. Videos are uploaded as private unless the owner changes the setting.

Facebook

Posts the vertical video as a Reel to a Facebook Page through the Meta Graph API.

TikTok

Uses the TikTok Content Posting API. Apps that have not passed TikTok's audit can only post privately, and the project reports exactly what the API returns.

Every platform can be switched on or off independently, and one platform failing never blocks the others.

Poems and rights

The project is meant for poems that are in the public domain or otherwise legally available. It does not invent poem text: if a poem cannot be retrieved reliably, nothing is published.
