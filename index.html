Kokoro Poetry Video

An open-source pipeline that turns one English poem a day into a narrated, subtitled poetry video — planned with AI assistance and published through official platform APIs.

What it does

Each day the project selects the next poem from a prepared list, asks an AI model once to prepare the materials the video needs, and then builds the video (including a vertical version for short-form platforms).

Poems are narrated with Kokoro text-to-speech. Because the narration is synthetic, the videos disclose this in their descriptions.

How it works

  1. Select — exactly one pending poem is chosen per calendar day. State is stored so the same poem is not processed twice.
  2. Plan — one AI request returns poem details, narration text, mood, voice choice, background scene plan, music search keywords, and platform-specific titles and descriptions.
  3. Gather — background footage is obtained from Pexels and a background track is located on Freesound (limited to Creative Commons 0).
  4. Narrate — Kokoro text-to-speech reads the poem line by line.
  5. Render — FFmpeg combines narration, synchronized subtitles, footage, and music (with music ducked while the voice speaks).
  6. Publish — when enabled, the video is uploaded through the official APIs of the selected platforms, and the result of each upload is recorded.

Building blocks

Kokoro TTS

Open-weight text-to-speech model used to narrate each poem with a voice suited to its mood.

Pexels

Free stock photos and videos used as cinematic backgrounds. Only the files needed for the current poem are downloaded.

Freesound

Background music is searched on Freesound and limited to tracks released under Creative Commons 0.

Subtitles & FFmpeg

One subtitle line appears at a time, timed to the narration, with a larger, mobile-safe layout for the vertical video.

Publishing

Publishing uses each platform’s official API with OAuth (or equivalent). Credentials are stored as GitHub Actions Secrets and are never written into the code, the logs, or the generated files.

YouTube

Uses the YouTube Data API v3 with the upload permission only. Videos are uploaded as private unless the owner changes the setting.

Facebook

Posts the vertical video as a Reel to a Facebook Page through the Meta Graph API when that platform is enabled.

TikTok

Uses the TikTok Content Posting API. The project posts only to the authorizing owner’s account and reports exactly what the API returns. Apps that have not completed TikTok’s audit may be limited to private or restricted visibility.

Every platform can be switched on or off independently. Failure on one platform does not block the others.

Poems and rights

The project is intended for poems that are in the public domain or otherwise legally available for the intended use. It does not invent poem text. If a poem cannot be retrieved reliably, nothing is published for that entry.
