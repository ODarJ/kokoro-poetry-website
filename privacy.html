Privacy Policy

Kokoro Poetry Video · Last updated: October 8, 2026

1. What this project is

Kokoro Poetry Video is an open-source automation that produces narrated poetry videos and publishes them to accounts owned by the project operator. It runs on GitHub Actions. It is not a service for the public: it has no user accounts, no sign-up and no website that collects information from visitors.

Source code: github.com/ODarJ/kokoro-poetry-video-

2. Google OAuth and the YouTube API

The project uploads videos to a YouTube channel through the YouTube Data API v3. To do this, the channel owner authorizes the project once using Google OAuth.

  • Permission requested: only the YouTube upload permission (https://www.googleapis.com/auth/youtube.upload).
  • What the project does with it: uploads the generated video, with its title, description, tags and privacy setting, to the authorizing owner's channel.
  • What the project does not do: it does not read the channel's other videos, comments, subscribers, analytics or any viewer data, and it does not collect data about people who watch the videos.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google user data is not sold.
  • Google user data is not used for advertising, and not used to build profiles.
  • Google user data is not shared with third parties, except as needed to perform the upload requested by the owner (the data goes to YouTube).
  • No person reads Google user data; the upload is performed automatically.

3. Where credentials are stored

OAuth client ID, client secret and refresh token (and the API keys for the other services) are stored as GitHub Actions Secrets in the project's repository. They are provided to the workflow as environment variables only while it runs. They are not written to source code, generated files, the saved pipeline state or logs; the pipeline masks known secret values in its own log output.

5. Other services involved

  • AI providers (Google Gemini, Groq, Mistral): receive the poem title, author and the planning prompt in order to prepare the video information. One request is made per poem. No Google OAuth data or credentials are sent.
  • Pexels: receives search keywords and returns photos or videos used as backgrounds.
  • Freesound: receives search keywords and returns Creative Commons 0 music used as background audio.
  • Facebook (Meta Graph API) and TikTok (Content Posting API): receive the video and its caption or description when those platforms are switched on.
  • GitHub: hosts the code, runs the workflows and stores secrets, state and artifacts.

Each of these services has its own privacy policy.

6. Visitors to this website

This website is static. It does not use cookies, analytics, advertising or forms. GitHub Pages, which hosts it, may process technical data such as IP addresses under GitHub's privacy statement.

7. Security

  • Secrets live only in GitHub Actions Secrets; they are never committed.
  • Only the minimum permission needed for uploading is requested.
  • Only one pipeline run can change the pipeline state at a time.
  • Videos are uploaded as private by default until the owner chooses otherwise.

8. Revoking access and deleting data

  • Google / YouTube: remove the project at myaccount.google.com/permissions. The stored refresh token then stops working; delete the GitHub secrets as well.
  • Facebook and TikTok: remove the app from your account's connected apps settings and delete the matching GitHub secrets.
  • Stored project data: delete the state/ folder and Actions artifacts, or delete the repository.
  • Uploaded videos: delete them on each platform.

9. Children

The project is not directed at children and does not knowingly collect personal information from anyone.

10. Changes and contact

This policy may be updated as the project changes; the date above shows the latest revision. For questions, open an issue at github.com/ODarJ/kokoro-poetry-video-/issues.
